# runway

## `runway.<field>`

Platform-provided values, resolved at render time. Current fields:

| Field          | Value                                                        |
|----------------|--------------------------------------------------------------|
| `runway.stack` | Stack name (user-picked or generated). Also the namespace.   |
| `runway.fqdn`  | The current service's internal DNS name inside the cluster.  |
| `runway.url`   | The current service's public URL. Invalid when `settings.route` is false. |

Unknown fields are a validation error. New fields may be added in later
schema releases without a version bump. A template that uses a field the
platform does not know yet fails validation at deploy time.

## `runway.secret(<n>)`

A random secret generated by the platform: `n` characters from
`[A-Za-z0-9]`, so the value is safe in DSNs, shells, and URLs without
quoting. `16 <= n <= 128`.

Identity and lifecycle:

- One secret per stack, service, and env key. The env key the expression is
  assigned to identifies the secret.
- Generated on the first deploy of the stack, stored encrypted, and reused
  unchanged on every later deploy and update. The platform never regenerates
  it on its own. Rotation is a user action.
- Deleted when the stack is deleted.
